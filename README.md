## `> WHAT IS MARROW`

Marrow is a **first-person roguelike wave survival game** built in Unity with a PS1 aesthetic. Survive escalating enemy waves, unlock perks between rounds, and push for a higher score every run. Inspired by the round-based survival loop of COD Zombies, rebuilt from the ground up with low-poly visuals, retro rendering, and roguelike progression.

> *Every run feels different. Every death is your fault.*

## `> PS1 AESTHETIC`

Marrow is built to look and feel like it came off a PlayStation 1 disc.

- **Affine texture warping** — the signature PS1 texture wobble, no corrections
- **Vertex snapping** — geometry jitter that makes everything feel slightly wrong
- **Limited color depth** — dithered shading, low-res rendering
- **Custom HLSL shaders** — hand-written ShaderLab for full control over the retro pipeline
- **Low-poly everything** — Blender-built assets built for the aesthetic, not polygon budgets
